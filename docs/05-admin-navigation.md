# 管理页面与来源索引 · 0.2.5

本次按桌面使用整理管理页面。每个一级菜单顶部直接展示全部二级按钮，一次显示一个面板；首次进入默认第一项，本次页面会话中保留上次选择。向下滚动时二级菜单固定在内容区顶部。

| 一级菜单 | 二级菜单 |
|---|---|
| 01 今日概览 | 当前概览、近期动态 |
| 02 上下文与提示词 | 上下文排序、上下文用量、提示词模板、模型试跑、调用记录 |
| 03 角色与状态 | 角色与世界、生活状态、内在状态、经历记录 |
| 04 日程与行动 | 日程与执行、生成与细化设置、日程档案 |
| 05 聊天与对象 | 聊天白名单、回复与插话、发送限制、发送记录 |
| 06 见闻与来源 | 来源设置、近期见闻、手动读取、日报执行 |

| 08 系统与数据 | 模型分配、模块开关、备份恢复、维护与诊断 |

## 上下文排序

从「02 上下文与提示词 → 上下文排序」进入。桌面行高 32px、行间距 4px；每行显示勾选框、拖动手柄、名称、来源、角色下拉框及上下按钮，原始人格及消息定位行只读。完整名称可悬停查看，也显示在来源说明中。

同一角色内从上到下就是实际注入顺序。拖动左侧手柄时显示插入线和占位行，其他行平滑让位，靠近窗口边缘可以滚动。松手到有效行或明确的组末尾区域才提交草稿；原位松手、Esc 取消和无效落点保持原顺序。system 与 user 可相互移动；原系统提示词、本轮原消息／任务提示词只读，但资料可以插到它们前后。也可用角色下拉框、上下按钮和键盘操作。减少动画偏好会关闭换位动画。

所有任务显示相同完整列表，包含未勾选资料。「调整范围」仅切换本任务的勾选项，排序全局共用；在任意任务下拖动、上下移动或切换 system／user 都修改这一套全局顺序。升级前已保存的全局顺序成为默认基准，旧任务独立顺序只归档。

点击「保存上下文设置」保存当前面板草稿；「恢复本任务默认勾选」只重置当前任务选项，「恢复默认排序」还原保存的排序基准。恢复操作先形成草稿，保存后下一轮生效。切换任务、来源跳转和保存失败均保留草稿，不再提供任务独立排序或恢复排序继承。

资料名称以实际二级菜单为前缀，记忆与画像、近期记忆独立勾选排序。通用资料按本轮场合读取；专用材料缺失跳过。保存勾选不触发业务；实际相关召回允许模型理解检索词，失败退回直接关键词检索。未勾选项不影响去重和反馈，工具后沿用原快照。详见[统一记忆指南](07-memory-system.md)。

## 来源说明与跳转

上下文排序每块和上下文用量每行的「来源」按钮打开右侧说明，包含用途、设置或资料来源、完整管理路径及确实生成该材料的相关任务模板。点击入口直接切到目标二级面板；记忆画像、日记／笔记、新闻、搜索、天气、B站和日报准确选中，具体字段高亮并获得焦点。相关模板显示原标识和中文说明。

「返回上下文列表／返回上下文用量」恢复原来选择的任务、编辑草稿及滚动位置。宿主人格和原始消息由 AstrBot／QQ 管理，来源说明中提供具体操作路径。

**这里是用途与管理入口索引，不是某次调用的逐条原始记录溯源。** 当前管理页的资料不被解释成历史调用当时采用的资料；历史同次来源和真实请求仍查看调用记录①②。索引说明和导航元数据不进入模型请求。

## 编辑与阅读

- 提示词先选任务，再选当前、内置默认或归档版本，一次显示一个编辑器；默认和归档版本只读。
- 来源设置先选类型，新闻源、日报作者和白名单对象各自下拉选择一个编辑，可新增、删除或恢复来源默认列表。内在状态下拉选择寂寞值或精力，应用当前值和保存阶段参数仍分开。
- 记忆、经历、见闻、日记和发送记录提供搜索及筛选，每页默认 10 条；点击标题阅读正文。日程保留所选日期的完整紧凑时间线，细化和执行详情按需展开。
- 调用记录先按类别和轮次选择，一次显示一轮，可切换前后轮。四项视图、轮内 HTTP 请求选择、原文复制下载、阅读格式化及折叠保持原功能。
- 保存、恢复默认和主要操作位于当前编辑面板顶部。真实模型／来源读取、日程重生成、后台记忆提炼及备份恢复仍按按钮说明执行；保存配置不会暗中调用模型。

## 草稿与兼容

草稿按面板和编辑对象保存在当前页面内存中。切换一级／二级菜单、下拉对象、来源跳转、数据刷新都保留输入。保存只提交当前面板负责的字段；例如发送限制不提交插话间隔，角色设定不提交模型和模块，天气设置不提交新闻源草稿。保存失败保留输入，保存成功不清除其他草稿。

关闭或重载浏览器时，存在未保存草稿会触发浏览器提示。不会把私人输入写入 localStorage；确认离开后草稿不保证恢复。记录弹窗中的修改同样参与离开提示；点击取消或关闭弹窗视为放弃该次弹窗编辑。

旧 `#settings`、`#drives`、`#whitelist`、`#social`、`#journal`、`#debug`、`#data` 链接仍可使用，自动定位新面板。日程档案和会话状态的调用链接继续匹配轮次或记录标识；已清理的调用明确提示，不伪造原文。旧模板、旧调用记录及数据库结构不改写，备份仍携带布局。

旧 `#memory?tab=usage` 定位到「02 上下文与提示词 → 上下文用量」。自身画像、每人画像、相关记忆、近期记忆和天气分别限量，人物数单独设置，合计只读；白名单保留可选对话称呼，模型仅看到目标名字／群聊名字及接收范围，失败显示“未设置名字”。主动聊天每轮只抽选一个群或私聊对象。回复与插话面板分别维护三份回复要求；完整及简版日程在上下文排序中互斥勾选，聊天默认简版。
