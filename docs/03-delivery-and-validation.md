## 自动化验证范围

本轮主程集成验证结果：

- 独立环境：Python **3.12.14**，安装本地 AstrBot **4.28.0b1**。
- `python -m pytest -q`：**140 项通过**。包含实际 AstrBot 类的插件初始化、页面 HTTP 请求适配、卸载重载和工具执行器验证；模型、网络内容及消息传输使用替身。
- `python -m ruff check main.py living_world tests scripts`、Python 格式检查及 JavaScript 语法检查通过。
- 真实无头 Edge 页面测试通过：导航、配置保留、记忆编辑、场合限制、XSS 防护、错误提示、主动发送确认、备份导入、手机布局。页面桥接使用替身，未连接真实 AstrBot WebUI 会话。
- 回归修复包含：排队模型请求的热关闭、人格与模型切换、OneBot 用户_群编号、私人社交结果不回流全局、无效备份无副作用、重启不重发、来源关闭后的衍生记忆过滤。

测试产生一项来自宿主 `audioop` 的 Python 弃用提醒，不影响本轮 Python 3.12 验证。以下按能力区分自动化验证与真实联调。

| 能力 | 已实现并纳入自动化验证 | 仍需真实环境确认 |
|---|---|---|
| 基础接入 | 人格与会话约束、模型选择、模块启停、数据库持久化与恢复；真实宿主类初始化和重载 | 在实际运行的 AstrBot 服务中安装、重载和在线模型调用 |
| 角色状态 | 精力情绪更新、状态保留、核心人格不被自动改写 | 长期表达的一致性与自然程度 |
| 日程生活 | 大纲与细化、虚构小插曲、未来安排调整、计划与执行分离、过期不补发、执行防重 | 实际模型生成质量、连续运行后的生活节奏 |
| 记忆 | 分类、中文检索、人物与场合过滤、更新合并、强化淡化、重要记忆保留 | 真实中文对话提炼质量和长期使用效果 |
| 外部来源 | RSS/Atom 解析、天气 JSON、搜索工具替身、B 站严格成功判定、出处保留、失败隔离 | 配置来源的在线可用性、B 站账号及视频解析 |
| 主动社交 | 加权随机抽选、数量、频率、免打扰、重复发送控制、群聊上下文与场合边界 | QQ 群聊/私聊收发、群历史读取、宿主概率回复配合 |
| 日记笔记 | 基于已有证据、场合继承、按日去重、来源开关及派生记录处理 | 真实经历回顾是否准确、没有补写不存在的回应 |
| 集中页面 | 配置与模块操作、记录查看维护、备份恢复接口、页面接入 | 在真实 AstrBot 中完成整套页面操作与视觉验收 |

自动化使用模型、消息与来源替身，避免把真实账号调用或发送结果混入测试结论。当前没有配置用于本轮实测的 QQ 连接、模型凭证和 B 站 Cookie，因此这些真实联调不记为已通过。

## 已知边界

- 这是单角色轻量生活插件；不包含完整世界模拟、其他居民自主运行、梦境、人格自我改写或复杂技能成长。
- 当前记忆为轻量中文文本检索，没有向量数据库。抽取、概括、日程和表达的效果仍需真实模型验收。
- 新闻、天气和搜索来源由使用者配置；B 站依赖 Bilibili AI Bot 的指定工具和公开记忆 API v3。缺少依赖只影响对应能力。
- 设置以 Plugin Pages 与插件数据库为准；不提供第二套 `_conf_schema.json`。更换目录或运行环境时应检查实际数据库位置。
- 恢复备份采用设置恢复、缺失记录合并和全部业务模块关闭；不覆盖已有 ID 和执行防重记录。
- 管理员修改、删除或合并记忆后会立即重核相应场合日程。重核模型失败时，相关未执行日程保留为待核对，不执行旧安排，后台稍后重试。
- 本轮不执行公开发布或插件市场上架。后续版本兼容范围、安装包和真实验收结果应继续更新本记录。

在开发仓库运行 `python scripts/build_test_package.py`，生成 `dist/astrbot_plugin_living_world-0.1.0.zip` 及 SHA-256 校验文件。包内只包含插件源码、页面、依赖声明、许可和文档，不包含环境、数据库、缓存或凭证。脚本检查 ZIP 完整性、入口文件及包内 Python 语法。
