# 02 角色资料与生活状态

## 任务内容

- 沿用 AstrBot 人格，补充可编辑角色资料与世界设定，核心人设保持固定。
- 提供轻量心情、精力和作息，适度影响生活及表达，不引入饥饿或复杂身体模拟。
- 根据设定与日程更新地点和睡眠状态，缺少依据时显示未知；私人活动信息只在所属场合使用。
- 首页展示当前状态并关联活动和真实天气，支持独立启停、人工调整和恢复。

## 依赖

- 基础接入、日程活动、和风天气与场合内记忆。
- 管理页面承接设定、状态展示及必要编辑。

## 验收效果

- 首页能立即看懂角色心情、精力、地点、睡眠、天气和当前活动。
- 状态有依据且跨重启保留，私人地点或经历不会流入其他聊天场合。
- 关闭状态模块停止对应推进，已有数据保留，核心人格不自动改写。
