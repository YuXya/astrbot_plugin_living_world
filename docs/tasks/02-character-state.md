# 02 角色资料与生活状态

## 任务内容

- 沿用 AstrBot 人格，补充可编辑角色资料与世界设定，核心人设保持固定。
- 角色状态保留心情与作息；独立“内在状态”模块管理寂寞值与精力，不引入饥饿或复杂身体模拟。
- 内在数值范围 0—100，默认每在线小时各加 10，离线不补涨、每天不重置、封顶不积攒。寂寞值初始 0，精力沿用旧值或新安装默认 70；增长与当前值均可人工修改。
- 日程主动聊天实际开始每轮默认减寂寞值 10；日程新闻、搜索实际开始分别默认减精力 10，各项可配置。多对象只扣一轮，开始前跳过不扣，开始后失败不退，余额不足允许执行并归零；其他来源操作、试跑、回复、插话、天气和日报不扣。
- 当前阶段想法默认仅在活动细化勾选，其他任务可自行勾选；AI 只收到本轮命中的自然语言文案，不收到数值、名称或机制，也不控制增减。默认 0—40、41—80、81—100 三阶段，支持拆分、删除合并和编辑，始终覆盖 0—100。“必须聊天”仅是强烈提示。
- 数值或参数改变不自动重细化；模块关闭停止增长、扣减和注入并保留数据。使用运行期单调时钟，每 60 秒及扣值、修改、正常退出时保存；行动开始与扣减在同一事务中防重，重启不补离线增长。
- 根据设定与日程更新地点和睡眠状态，缺少依据时显示未知；私人活动信息只在所属场合使用。
- 首页展示当前状态并关联活动和真实天气，支持独立启停、人工调整和恢复。

## 依赖

- 基础接入、日程活动、和风天气与场合内记忆。
- 管理页面承接设定、状态展示及必要编辑。

## 验收效果

- 首页能立即看懂角色心情、精力、地点、睡眠、天气和当前活动。
- 状态有依据且跨重启保留，私人地点或经历不会流入其他聊天场合。
- 关闭对应模块停止其推进，已有数据保留且可人工调整，核心人格不自动改写。阶段预览与下次细化输入一致，刷新不覆盖未保存设置。
- 数值与阶段边界、跨日、重启、执行失败、并发和备份恢复行为可验证；所有插件提供的模型请求不含内在数值机制，旧 energy_delta 不再生效。
