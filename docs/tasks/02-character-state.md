# 02 角色资料与生活状态

> 状态：0.1.0 已实现并纳入自动化验证；真实模型下的角色连续性验收待完成。返回[主程总计划](../01-lead-plan.md)。

## 做什么

- 沿用 AstrBot 人格，提供角色资料、世界设定的补充与编辑能力，让日程、聊天和主动表达使用一致的角色背景。
- 保持核心人设固定，由用户修改设定；经历、知识和人物关系可以积累，不安排 AI 自行改写人格。
- 提供适度自定义的精力、情绪和作息，让生活状态轻微影响活动选择与表达。不要饥饿系统，不扩展为完整世界模拟。
- 随日程推进和实际互动更新当前生活状态，保持活动、感受与后续表达连续；支持查看和必要的人工调整。
- 提供运行时开关，关闭后停止对应行为并保留资料与状态，其他能力继续工作。

## 依赖

- 基础接入提供 AstrBot 人格、模型、模块启停和恢复能力。
- 与日程、记忆和聊天任务对接角色背景与当前状态；集中管理页面承接编辑、查看及恢复操作。

## 验收效果

- 同一角色在日程、群聊和私聊中保持一致的人设，修改补充资料后能用于后续活动。
- 疲惫或无聊能适度改变活动和表达，持续积累的记忆不会自行重写核心人设。
- 重启后恢复当前资料与状态；运行中关闭能力后停止状态推进，已有数据仍可查看。
