# 01 基础接入与模块管理

> 状态：0.1.0 已实现并纳入自动化验证；真实宿主与 QQ 联调待完成。返回[主程总计划](../01-lead-plan.md)。

## 做什么

- 接入 AstrBot 人格、模型、会话与消息能力，首发支持 OneBot QQ 群聊和私聊。插件沿用 AstrBot 人格，补充角色资料与生活能力。
- 默认沿用 AstrBot 已配置模型，并允许设置全插件默认模型及各业务模块的模型覆盖。
- 建立模块注册、运行时启停、运行状态查看和恢复能力；所有业务能力分别提供开关，关闭后保留已有数据，重新开启可继续使用。
- 提供日程执行、记忆读写、外部调用和主动社交需要的共用能力，协调各模块接入，确保单个模块或调用失败不拖垮插件。
- 完成独立安装与运行支持，无需安装 private_companion 或 Angel Memory；为集中管理页面提供基础入口和运行信息。
- 使用 AstrBot Plugin Pages 统一管理配置，默认未绑定人格时不自动行动。

## 依赖

- 以主程总计划为产品依据，结合仓库中的 AstrBot 接入方式开展工作。
- 与各任务负责人确认共用能力需求；主程负责依赖协调、跨模块联调和整体验收。

## 验收效果

- 单独安装本插件即可在 QQ 群聊和私聊中工作，能够使用当前人格及配置的模型。
- 修改模块模型配置后，对应模块使用所选模型，未覆盖的模块继续使用默认模型。
- 运行中关闭某项能力后，对应行为停止，其他能力正常工作；重新开启时已有数据仍可用。
- 重启后接续已有日程和记忆，过期主动消息不集中补发，失败状态能够在管理入口查看。
