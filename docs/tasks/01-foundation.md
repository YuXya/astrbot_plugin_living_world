# 01 基础接入与模块管理

## 任务内容

- 支持 AstrBot 4.27.5 至 5 以前版本的 OneBot QQ 群聊与私聊，绑定一个宿主人格，接入真实会话、模型和消息能力。
- 按实际 UMO 和宿主设置解析默认／当前对话／会话规则人格，配置检查与执行共用结果，分别诊断连接、平台、人格和模块失败；4.27.5 需验证默认人格参数的实际行为。
- 提供插件默认模型与业务覆盖、共用后台执行、持久化、模块状态及运行时启停。关闭保留数据，单项失败隔离。
- 统一模型、工具、实际发送的调用记录；调试存储与正式日程、记忆和防重记录分离。
- 按聊天轮次隔离 Provider 调用，支持工具后的再次调用、流式结果、异常与取消；关闭调试和卸载恢复包装，记录失败不能影响业务。
- 提供 Plugin Pages 唯一管理入口，清理卸载/重载任务与注册路由；生活和记忆独立安装。
- 升级保留旧记忆、白名单、当天已有日程与执行记录；备份恢复合并缺失记录并关闭全部业务模块。

## 依赖

- 主程总计划，以及生活、记忆、来源、社交和页面的共用接口需求。
- 宿主人格、模型、平台连接与 Plugin Pages 能力。

## 验收效果

- 未绑定人格或会话人格不匹配时不接入；模型选择、模块开关与页面显示一致。
- 关闭模块、取消调用、重载与重启后无重复行动、集中补发或数据丢失。
- 本地自动化、4.27.5 官方源码核对和真实宿主验收分别记录。
