# 08 集中页面、调试与测试

## 任务内容

- 管理页面按 8 个一级菜单和顶部直接可见的二级面板分工，完整菜单见[管理页面指南](../05-admin-navigation.md)。「02 上下文与提示词」包括上下文排序、上下文用量、提示词模板、模型试跑、调用记录。旧页面和关联调用链接自动定位到新面板。
- 上下文位置按 system、user 分组，从上到下对应实际注入。支持拖动、上下按钮、角色切换，原系统提示词和本轮消息／任务提示词作为只读定位行。所有任务显示相同完整资料列表，除只读定位行外均可勾选，包含未选行。“调整范围”仅切换本任务勾选项，任意任务下移动都修改唯一全局顺序及 system／user 位置；原已保存全局顺序作为默认基准，旧任务独立顺序归档。提供保存上下文设置、恢复本任务默认勾选、恢复默认排序，恢复先形成草稿。记忆七类、综合见闻、天气和任务专用材料独立排序，四类见闻合并按时间取数并保留标签，结构化证据内部保持完整。
- 正式调用和组合试跑共用目录、校验及组装器。保存拒绝重复、非法角色、未知或缺少标识；保存后下一轮生效，每轮冻结全局顺序、任务勾选、资料及三份回复要求，在途工具调用保持快照。通用资料按本轮场合读取，专用材料只用本次明确输入、缺失跳过；勾选不触发来源读取或额外任务，未勾选记忆不强化、不参与已选资料去重。任一角色临时资料不进入宿主历史，移动不增加召回内容，不改变旧记录和模板。
- 使用 AstrBot Plugin Pages，首页优先展示心情、精力、地点、天气、睡眠、当前活动、时间线和下次主动联系。
- 「03 角色与状态 → 内在状态」面板顶部同时展示寂寞值和精力的当前值、阶段及下次细化注入文案；下方用下拉框选择单列编辑面板。增长、各类行动消耗和阶段可配置，应用当前值与保存参数分开，刷新预览不覆盖未保存内容。
- 当前值采用行内输入与应用，增长和各项消耗横向排列、窄屏换行，详细规则默认折叠；顶部状态卡片保持紧凑。
- 阶段采用桌面单行、手机双行的紧凑编辑布局，完整覆盖 0—100。行内加号约分当前区间、沿用文案，删除并入低一档、最低档并入下一档；仅剩一档时不可删除，单值阶段不可拆分。分界编辑联动相邻范围，禁止重叠和空档。“必须聊天”说明为强烈提示，非程序强制执行。
- 日程页管理大纲生成和细化参数，移除三个每日活动上限。活动内显示细化理由、意图、时间与执行结果，以及已安排、已开始、成功、失败和跳过统计；旧版本真实行动继续计入。提供独立白名单入口、新闻/搜索感想与历史、来源和角色模型模块配置。
- 未开始活动支持「细化活动／重新细化」和可选本次要求，说明真实模型调用与临时要求不入公共模板；展示失败和有限自动重试。大纲编辑及批量调整不传旧行动决定，修改后作废旧细化，旧细化版本可折叠查看。
- 提供「重新生成日程」及可折叠历史，提示只重生成今天、使用已保存参数、真实模型调用及未来活动细化后照常执行；内在数值和实际行动记录不重置。参数未保存或正在生成时阻止重复操作，保留旧活动及实际结果档案。
- 「调试与调用记录」每轮固定四项：上下文来源、API 原始请求、API 原始返回、回复阅读版；工具后模型调用和 HTTP 重试通过请求选择器逐次配对，原文直接复制下载。聊天默认 10 轮、后台每类 10 次完整调用，按整组清理。模型分配与模块开关独立放入「08 系统与数据」。
- 仅收到普通消息不创建调试轮次、不占保留名额；模型处理或实际发送开始时才记录。更新重载及恢复旧备份清理可确认的纯观察旧轮次，保留真实失败、未捕获原文的调用及发送记录；群观察和白名单接入状态独立保留。
- 白名单显示当前真实会话、人格及找到历史／首次对话／读取失败，提供不调用模型、不发送、不创建会话的检查按钮。
- 白名单以紧凑摘要展示配置接入、人格和最近实际注入，拒绝原因与读取错误直接可见；会话编号、历史来源及轮次放入默认收起的详情，展开后仍保持紧凑。检查与调试入口并排，手机输入项两列排列。
- 原文来自现有 SDK HTTP 客户端；保留未知字段和 SSE，原文保存与阅读解析隔离。隐藏已知认证凭据，不误删普通同名字段；旧快照与未适配接口明确标注，不冒充已捕获原文或第三方内部调用。
- 允许从记录或当前配置建立并编辑测试请求，区分模板+动态上下文与完整 prompt 两种模式；试跑只调用模型，不执行工具、不发 QQ、不写正式业务数据。
- 公共任务模板单独保存与恢复，私人测试上下文和临时细化要求不自动写入模板；升级前自定义模板另有按任务及版本下拉选择的只读入口，当前使用匹配新流程的默认模板。不支持直接回放的特殊内容明确拒绝。
- 按钮说明用途、影响与真实调用；「整理旧记忆」置于高级操作，解释淡化、归档和重要保留。
- 提供必要记录编辑、删除、备份及恢复，管理员视图与聊天资料权限分开。
- 七类记忆、近期经历、综合见闻及天气分别设置独立上限，初始分别 4／2／1／1／2／1／1／10／5／1，合计 28 条只读，无隐藏总上限；日记和笔记简报各自最多 200 字符。用量位于「02 上下文与提示词 → 上下文用量」，0 停止该类自动注入但保留存档，所有自动召回共用规则。名称以真实二级菜单为前缀，排序、用量、分类、来源、新调用①和注入标题共用目录。每类用量均有来源按钮，可定位分类和字段、返回原位置，失败和跨面板保存保留草稿。
- 「05 聊天与对象 → 回复与插话」分别编辑或恢复群聊、私聊及主动聊天回复要求，各自最多 8000 字符、留空关闭；升级新增两份首次复制原群聊内容（含空值），之后独立保存。默认分别用于 chat.group、chat.private、social.message，插话判断默认不勾选；所有任务可自行勾选，要求保持独立指令形式并按全局排序注入。只保存本面板负责的回复与插话字段，不携带发送限制或白名单旧值。

- 桌面上下文行高 32px、间距 4px，单行显示勾选框、手柄、名称、来源、角色和上下按钮。拖动有插入线、占位和换位动画；原位、取消、无效落点不改变顺序、不标记草稿，只有明确末尾落点才追加到最后。
- 统一资料块目录补充用途、来源说明和稳定导航目标。来源按钮打开侧边说明，定位面板、下拉对象及相关字段；可返回原任务和滚动位置。只索引用途与管理入口，不增加某次调用逐条原始记录溯源，不把说明元数据注入模型。
- 草稿按面板和对象在内存中隔离，导航、下拉切换、来源跳转和刷新保留；保存只提交本面板字段，失败保留、成功不清其他草稿，关闭或重载提示未保存，不写 localStorage。
- 新闻源、日报作者、白名单及模板一次选一个编辑；经历、见闻、记忆、日记和发送记录支持搜索筛选、每页 10 条和点击阅读。调用记录按类别及轮次下拉选择，保留前后轮及四项视图；日程保留当天完整紧凑列表，操作置顶。
- 用户最新要求以桌面为本期验收重点，手机适配不作为交付门槛。

## 依赖

- 基础提供认证页面桥接、模型、调试、模板及恢复接口。
- 各业务模块提供真实配置、状态、档案和操作结果，页面随功能联调。

## 验收效果

- 移动综合见闻及群聊回复要求到 system、调换各类记忆与经历后，①的角色、顺序、实际数量及采用上限与②一致。验证十类独立额度、0 值、无隐藏总限制、场合与模块过滤、全局顺序同步及独立勾选、v3 幂等迁移、旧快照试跑、桌面布局和来源返回。验证简版日程与完整版本互斥、目标名字回退、三份回复文案独立保存及在途快照。
- 打开首页即可看懂角色当前状态，白名单、大纲参数和内在状态能直接找到，状态未知时不虚构；细化／重新细化和失败重试反馈清楚。旧精力编辑入口移入内在状态页面，首页精力来自新服务。
- 完整请求与原始 JSON 可复制下载，整轮保留数量正确；新记录不重复保存 `response` 和 `reply`，消息组件显示正文；清理调试不删除正式日程、记忆、群观察或防重记录。
- 试跑和保存模板没有隐含业务副作用；操作失败有明确原因，桌面布局可用。
- 管理员可查看所有场合，实际聊天仍过滤私人资料，备份恢复后全部模块关闭。
