# 08 集中页面、调试与测试

## 任务内容

- 使用 AstrBot Plugin Pages，首页优先展示心情、精力、地点、天气、睡眠、当前活动、时间线和下次主动联系。
- 提供日程参数与原始生成档案、独立白名单入口、新闻/搜索最新感想与历史、来源和角色模型模块配置。
- 新增「调试与调用记录」，记录插件模型请求、原始回复、工具参数/结果和实际发送；每类默认 10 次，支持复制、下载和独立清理。
- 明确 AstrBot 参数、被动回复钩子快照和第三方结果的捕获边界；隐藏认证字段，不冒充 HTTP 最终请求或第三方内部调用。
- 允许从记录或当前配置建立并编辑测试请求，区分模板+动态上下文与完整 prompt 两种模式；试跑只调用模型，不执行工具、不发 QQ、不写正式业务数据。
- 公共任务模板单独保存与恢复，私人测试上下文不自动写入模板；不支持直接回放的特殊内容明确拒绝。
- 按钮说明用途、影响与真实调用；「整理旧记忆」置于高级操作，解释淡化、归档和重要保留。
- 提供必要记录编辑、删除、备份及恢复，管理员视图与聊天资料权限分开。

## 依赖

- 基础提供认证页面桥接、模型、调试、模板及恢复接口。
- 各业务模块提供真实配置、状态、档案和操作结果，页面随功能联调。

## 验收效果

- 打开首页即可看懂角色当前状态，白名单和日程参数能直接找到，状态未知时不虚构。
- 完整请求与原始 JSON 可复制下载，每类数量正确；清理调试不删除正式日程、记忆或防重记录。
- 试跑和保存模板没有隐含业务副作用；操作失败有明确原因，桌面及手机布局可用。
- 管理员可查看所有场合，实际聊天仍过滤私人资料，备份恢复后全部模块关闭。
