# 08 集中管理页面

> 状态：0.1.0 已实现并纳入自动化验证；真实宿主页面与完整配置操作验收待完成。返回[主程总计划](../01-lead-plan.md)。

## 做什么

- 使用 AstrBot Plugin Pages 建设集中管理页面，统一管理全部保留能力，不维护第二套插件配置入口。
- 管理角色资料、世界设定、生活状态、日程、模块开关、默认模型与模块模型覆盖。
- 管理新闻、搜索、天气和 B 站来源，以及主动对象白名单、对象权重、抽选数量、频率和免打扰配置。
- 查看当前活动与模块运行状态、记忆、人物认知、外部见闻、日记和见闻笔记。
- 查看日程执行、主动调用、主动消息和模型调用情况，能够了解活动是否实际执行、调用是否成功及模块为何不可用。
- 提供必要的编辑、删除、导入导出与恢复操作，使用户能够维护角色资料、日程、记忆和相关配置，并看到操作结果。
- 恢复备份时恢复设置、合并缺失记录，不覆盖已有 ID 和执行防重记录；所有业务模块保持关闭，检查后再启用。

## 依赖

- 基础任务提供管理入口、模块运行信息和共用管理能力。
- 各业务负责人提供所属能力的配置、查看和必要管理操作；页面与模块同步联调，避免出现仅展示的功能入口。

## 验收效果

- 用户能在同一页面完成角色、模型、来源、白名单和模块开关管理，修改结果与实际运行一致。
- 日程计划与已执行活动、不同场合的记忆、真实见闻与角色经历能够分辨，主动消息及调用结果可以查阅。
- 运行中关闭模块后，对应行为停止且历史数据仍能查看；再次开启后可以继续使用。
- 必要数据能够编辑、删除、导出并恢复；操作失败有可理解的提示，不会被显示为成功。
