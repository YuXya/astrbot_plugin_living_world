# 06 聊天与主动社交

## 任务内容

- 被动回复、群聊插话与日程主动聊天分别可控；主动分享与找人聊天均由日程聊天标记安排。
- 取消日程外临时主动联系入口；计划文本不提前冒充已发送消息，实际表达在执行时生成。
- 提供独立「聊天对象与白名单」入口，首页和日程直达；表单填写 QQ 连接、群聊/私聊、号码、启用和权重，兼容旧 UMO。
- 按真实目标加权随机抽取配置数量的不同对象，统一冷却、每日上限、免打扰及防重复控制。
- 每个目标使用真实会话人格、聊天历史和记忆，结合该活动之前取得的见闻选择话题，分别生成内容。
- 检查宿主群历史与概率回复，避免重复插话；记录实际发送、跳过和失败，不假定对方已经回应。

## 依赖

- 基础 OneBot 消息、人格与真实会话接入。
- 日程聊天标记、相关记忆及真实见闻；页面负责目标和发送规则配置。

## 验收效果

- 带聊天标记的“数学课无聊”能实际抽选并联系目标，未标记活动不触发计划社交。
- 低权重目标仍有机会被选中，一次不重复选同一目标，实际次数受发送控制而非强行凑满。
- 同群独立用户会话正确匹配目标，私人内容不串群；关闭主动社交不妨碍已开启的正常回复。
