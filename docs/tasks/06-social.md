# 06 聊天与主动社交

> 状态：0.1.0 已实现并纳入自动化验证；QQ 测试白名单收发与群聊插话实测待完成。返回[主程总计划](../01-lead-plan.md)。

## 做什么

- 支持正常被动回复、适度群聊插话、生活见闻分享和主动找人聊天，相关业务能力分别提供运行时开关。
- 向模型提供主动社交调用能力，既能由日程安排执行，也能在活动过程中临时发起。例如“数学课无聊，找个群聊聊天”能够成为实际行动。
- 让日程社交、模型临时社交和生活分享共用白名单、对象权重、抽选数量、频率、免打扰及重复发送控制。
- 按权重概率随机抽取配置数量的不同对象，保留低权重对象被选中的机会，不采用相关性排序取前几名。
- 为每个选中对象分别读取对应聊天场合的上下文与相关记忆，选择话题并生成内容。认识同一个人时可使用稳定人物认知，私人谈话和约定保持所属场合。
- 记录实际联系与互动结果，供后续聊天、日程和记忆使用；消息发出与收到回应分别记录，尚未执行的聊天计划不能记为已发生的互动。

## 依赖

- 基础接入提供 OneBot 群聊、私聊、模型及消息能力。
- 日程提供计划行动和临时意愿；记忆提供人物认知与场合内经历；外部见闻提供可分享内容。
- 管理页面提供白名单、权重、数量与主动消息控制及记录查看。

## 验收效果

- “上数学课时找群聊天”能按日程发起，结合目标群话题发言；活动中临时调用也能完成同样流程。
- 同一次抽选不会重复选中对象，低权重对象仍有机会被选中，各目标收到符合自身场合的表达。
- 三个主动入口均遵守统一控制，私人聊天内容不会自动成为群聊分享。
- 关闭主动社交后不再主动联系，正常被动回复仍可运行；失败和未执行计划不会成为成功互动记忆。
