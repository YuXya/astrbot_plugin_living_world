# 06 聊天与主动社交

## 任务内容

- 被动回复、群聊插话与活动主动聊天分别可控；主动分享与找人聊天在活动细化时按需要决定，不在每日大纲中凑足次数。
- 取消日程外临时主动联系入口；计划文本不提前冒充已发送消息，实际表达在执行时生成。
- 提供独立「聊天对象与白名单」入口，首页和日程直达；表单填写 QQ 连接、群聊/私聊、号码、启用和权重，兼容旧 UMO。
- 无每日主动聊天轮次上限。找到符合限制的目标并开始生成消息才计一轮，且日程主动聊天扣一次寂寞值，失败不退；没有合格目标则不扣。重生成和重启不重置实际行动记录或重复扣值。
- 按真实目标加权随机抽取配置数量的不同对象，一轮多目标只计一轮；每个对象继续遵守独立发送上限、冷却、免打扰及防重复控制。
- 每个目标使用真实会话人格、聊天历史和记忆，结合该活动之前取得的见闻选择话题，分别生成内容。
- 聊天注入当前时间、当前活动及当天日程摘要，使用所属场合的调整；无日程或模块关闭明确标记。配置允许与最近实际注入分别记录，可关联调试轮次。
- 支持未聊过的对象，页面只读检查连接、人格、真实会话和历史；私聊使用当前对话，成功主动联系后写入宿主会话。
- 群消息独立观察，默认 24 条、12,000 字符，宿主历史可初始化；生成时替换重复群历史、保留引用和成员信息，保存前恢复。接管失败沿用宿主；私人资料不进群。
- 检查宿主概率回复，避免重复插话；记录实际发送、跳过和失败，不假定对方已经回应。
- 普通群聊的“本轮群聊回复要求”独立于人格和生活资料，固定放在本轮 user 最后；默认极短接话、通常一句，可编辑及恢复默认，留空不附加。临时文案不入历史，当前轮使用请求开始时快照，后续工具调用继续保留；其他插件的晚加入内容和媒体不得排在它之后。私聊、日程生成及其他后台任务不附加，不增加复核模型调用或截断输出。

## 依赖

- 基础 OneBot 消息、人格与真实会话接入。
- 活动细化的聊天决定、内在状态提供的自然语言想法、相关记忆及真实见闻；页面负责目标和发送规则配置。

## 验收效果

- “数学课无聊”在细化决定聊天后能抽选并联系目标，未安排聊天的活动不触发主动社交；公共细化不读取私人发送正文。
- 低权重目标仍有机会被选中，一轮不重复选同一目标，多目标只计一轮并扣一次，继续受每个目标的每日发送上限、冷却和免打扰约束。
- 同群独立用户会话正确匹配目标，私人内容不串群；关闭主动社交不妨碍已开启的正常回复。
- 首次联系后能接续，切换对话不拼入旧全文；观察不依赖插话或宿主群历史开关，重载不损坏原始历史。
