# 04 记忆与人物认知

## 任务内容

- 提供知识、事件、技能、情感分类，以及人物画像、共同回忆和角色自身体会，无需安装参考插件。
- 从生活、聊天和真实见闻提炼记忆，提供主动记忆、中文检索、更新、合并、强化、普通记忆淡化与重要记忆保留。
- 日程、聊天、主动表达和日记使用相关记忆；更新后旧内容失效，日程核对只处理允许修改的未来活动。
- 认识同一个人，谈话分场合：稳定称呼、兴趣与关系可贯通，具体谈话、约定和衍生内容保留场合。
- 保留来源，区分虚构经历、未执行计划和真实结果；源模块关闭时不通过衍生记忆绕过开关。
- 提供独立启停、管理员编辑和高级「整理旧记忆」，关闭业务召回/提炼后保留数据。

## 依赖

- 基础的人格、真实会话、人物识别、模型和存储。
- 生活、聊天、来源提供有依据的材料；页面承接查看、编辑、合并和恢复。

## 验收效果

- 更新后的约定替代旧内容，重复记忆可合并，重要经历保留。
- 同一人在不同群和私聊被认出，私密谈话不进入其他场合或全局计划。
- 整理旧记忆说明淡化、归档和重要保留，调试清理不影响记忆。
