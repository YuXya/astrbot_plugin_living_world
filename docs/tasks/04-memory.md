# 04 统一画像记忆与召回

## 任务内容

- 将经历、交流、搜索所学、上网摘要、日记和笔记统一提炼为记忆。自身档案按人格名称，其他人物按 QQ 身份；人格改名不混用旧自身档案，改回原名可继续使用。
- 五种画像属性为用户别名、事实属性、技能树、关系图谱、活跃项目，支持检索标签。保存结论、事实依据、稳定／推断标记、来源、真实时间、场合和版本；核心人格仍由用户维护。
- 普通聊天默认累计 5 轮或闲置 10 分钟提炼，来源材料保存后立即排队；批次与进度持久化，按场合隔离。AI 新增、修正、合并经程序校验后事务应用，失败保留原件。
- 提供主动记忆、主动召回、画像直取和普通模型扩词＋中文词片 BM25 相关召回，15 秒失败回退，不依赖向量。内部记忆步骤直接检索避免递归调用。
- 记忆与画像、近期记忆分别勾选及排序。默认自身画像 5、每人画像 5、相关记忆 10、近期记忆 5，群聊最多 3 人。近期自身记忆跨日按真实时间取最近记录，优先去重；未选部分不占额度。
- 有用性反馈只针对本轮实际提供的记忆，失败或缺失不奖惩，每轮每条一次。取消原自动强化。
- 遗忘默认关闭，只累计在线且双开关开启时间。低档每 3 在线日减强度 1，有用反馈增加强度和有用分，中档只因无用反馈淡化，长期档保留。主动记忆和重要项受保护；遗忘彻底删除记忆及版本，原来源与处理标记保留。
- 升级归档旧数据和配置，自动分批整理旧资料，保留归属、场合和原时间；可暂停、继续、重试，人格未解析时暂停。备份带新配置和进度，无 SQLite 表结构迁移。
- 页面支持档案、属性、场合、保留状态筛选，搜索、编辑、重要标记、删除、版本查看，以及提炼和遗忘参数、后台进度管理。

## 依赖

- 基础的人格、真实会话、QQ 身份识别、宿主模型、存储、调试与生命周期。
- 生活、聊天、来源和写作模块提供有依据的材料。稳定画像按权限互通，私人谈话及衍生资料保留场合，来源模块关闭不能绕过限制。

## 验收效果

- 批次、闲置、即时来源、重启续跑、失败重试和来源去重有效，旧经历迁移不会变成最近发生的经历。
- 换称谓提问可通过扩词召回，超时直接搜索；仅近期记忆不增加模型，主动召回可查询全部合规有效记忆。
- 人格改名与切回、QQ 档案延续、属性与推断证据、跨场合隔离、三档遗忘及彻底删除均覆盖。
- 正式和试跑共用选择与组装；试跑不写正式记忆、不强化、不遗忘、不发送 QQ，工具后沿用基础快照。
