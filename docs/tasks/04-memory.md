# 04 记忆与人物认知

> 状态：0.1.0 已实现并纳入自动化验证；真实聊天提炼和长期运行效果验收待完成。返回[主程总计划](../01-lead-plan.md)。

## 做什么

- 借鉴 Angel Memory 的知识、事件、技能、情感分类，建设人物画像、共同回忆与 AI 自身体会，独立提供能力，无需安装参考插件。
- 从生活、聊天和外部见闻中自动提炼记忆，并提供主动记忆能力；支持检索、更新、合并、有用记忆强化、普通记忆淡化与重要记忆保留。
- 将相关记忆提供给日程、被动聊天和主动表达，让既有约定、经历、兴趣和关系参与后续生活。
- 遵循“认识同一个人，谈话分场合”：同一人的称呼、稳定兴趣和关系认知可以贯通，具体谈话、私人经历和约定保留所属场合。
- AI 自己的生活经历和公开见闻共同使用；保留信息来源与场合，区分角色虚构经历、真实网络信息和计划，实际调用只有执行后才记为已发生。
- 提供运行时开关，关闭后停止记忆提炼、主动写入、自动维护和召回，保留已有数据；管理页面仍可查看保留数据并进行必要的编辑、删除、导入导出和恢复。

## 依赖

- 基础接入提供模型、会话、人物识别及持久化能力。
- 角色状态、日程、外部见闻与聊天提供经历和使用场合；管理页面承接人物认知与记忆的查看维护。

## 验收效果

- 聊天形成的约定能够影响日程，更新后的记忆替代旧内容，重复经历可合并，重要经历持续保留。
- 群聊与私聊能够认出同一个人，私人谈话不会自动进入其他场合的召回或群聊分享。
- 日程、聊天和主动表达均能使用适合当前场合的记忆；关闭后不再使用记忆，恢复启用仍可读取保留的数据。
