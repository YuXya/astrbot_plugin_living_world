# 03 日程与生活小插曲

> 状态：0.1.0 已实现并纳入自动化验证；真实日程与 QQ 行动闭环验收待完成。返回[主程总计划](../01-lead-plan.md)。

## 做什么

- 结合人设、生活状态和相关记忆生成每日大纲，临近活动时细化；聊天约定、临时见闻和互动结果能够调整日程。
- 安排适量角色日常与生活小插曲，保持前后连续，并区分角色虚构经历和真实外部信息。
- 让日程能够安排阅读、搜索、找群或个人聊天等实际调用；活动过程中也能临时起意调用这些能力。
- 打通“数学课无聊，找个群聊聊天”：产生社交意愿后调用主动社交能力，由该能力选择目标、结合对应场合的话题发言。
- 将计划与实际执行结果分开；计划中的搜索或社交只有执行后才记为已发生，失败、跳过和无人回应不得写成成功互动。
- 提供运行时开关和恢复能力；关闭后保留日程，重启后接续当前安排，过期主动消息不集中补发。

## 依赖

- 基础接入、角色状态和记忆提供生成日程所需的背景。
- 外部见闻与主动社交提供实际行动能力及结果；社交共用白名单、抽选、频率和免打扰控制。
- 管理页面承接日程查看与调整，日记任务使用已发生的经历。

## 验收效果

- 昨天的聊天约定能影响今天日程；“上课忘带笔”可成为之后聊天记得的小插曲。
- 日程安排或临时起意均能触发实际社交，并记录真实执行结果。
- 关闭行动能力或调用失败时，角色生活仍能继续，不会捏造搜索结果或已发生的聊天。
