# 03 日程、行动与生活小插曲

## 任务内容

- 每天默认 06:00 生成一份正式日程，默认 10 个活动，AI 选择新闻 2、搜索 2、聊天 3 个标记；数量与时间可配置。
- 生成 JSON 保留时间、活动、地点、睡眠及各行动的启用、意图和执行时间；严格校验活动数和三类标记数。
- 允许标记重叠，按新闻、搜索、聊天顺序每类执行一次；计划、实际成功、失败和跳过分别记录。
- 临近活动细化与生成适量小插曲；新的记忆、约定和见闻只调整未开始活动，维持配额并保留已执行记录。
- 不新增独立随机探索和临时主动联系。首次启动缺少当天日程才补生成，已有日程及升级前当天安排保留，过期行动不补发。
- 日程页集中管理生成参数，默认次日生效；保存正式参数、完整请求、原始 JSON 和采用结果。

## 依赖

- 基础、角色状态、按场合过滤的记忆及持久化。
- 来源与社交负责实际调用结果，页面负责参数、档案、时间线及未来活动调整。

## 验收效果

- 默认日程恰好 10/2/2/3，重叠正确，不合格结果不能进入正式日程。
- “数学课无聊找群聊天”只有带标记才按计划触发，表达能够使用此前成功读取的见闻。
- 昨日约定和更新后的记忆影响所属场合未来安排，已执行和开始活动保持。
- 关闭、失败、重启和局部编辑不额外增加配额、重复执行或泄露私人内容。
