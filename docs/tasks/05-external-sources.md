# 05 外部见闻与独立 AI 日报

## 任务内容

- 新闻内置 BBC 中文、Google 新闻中文、Solidot、Hacker News、MIT Technology Review、Ars Technica，可逐项修改、启停和恢复默认。
- 新闻取得候选后由 AI 选择、实际读取并写感想；搜索结合活动和记忆选题，自动调用 AstrBot 已配置网页搜索，再保存见闻。
- 天气固定和风，提供地点、API Host、API Key/JWT 配置及连接测试；自动刷新 90 分钟、失败退避 15 分钟，不调用 AI。
- B 站固定 Bilibili AI Bot，提供视频搜索、指定 BV 观看、公开视频记忆 API v3和必要只读视频信息查询，显示依赖状态。
- 独立定时读取黑鸦 Heya 12:00、橘鸦 Juya 23:00 两路 AI 日报，各路每天一次，可改时间，不占活动或新闻配额、不额外聊天、不重启补读。
- 见闻保存标题、选题理由、事实摘要、角色感想、来源和阅读依据；私人查询留在所属场合。
- 新闻、搜索、天气、B 站和日报分别启停；记录实际调用与失败，缺少依赖只影响相关能力。

## 依赖

- 基础模型、宿主只读搜索、调试审计、存储与模块生命周期。
- 日程提供带标记的行动，记忆提供相关上下文，页面提供设置和见闻历史。

## 验收效果

- 四类来源产生有依据的见闻，正文不可用时注明标题/摘要依据，失败不伪造感想或成功记录。
- B 站搜索、旧记忆和新观看可区分；日报确认作者与当日日期，不能确认明确跳过。
- 日报独立于 10/2/2/3 配额，天气刷新不调用模型；关闭与重启不会重放过期读取。
