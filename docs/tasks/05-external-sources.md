# 05 外部见闻

> 状态：0.1.0 已实现并纳入自动化验证；真实来源和 B 站账号联调待完成。返回[主程总计划](../01-lead-plan.md)。

## 做什么

- 分别建设新闻、搜索、天气和 B 站能力，四类来源均列入完整功能目标，并分别支持运行时开关。
- 新闻使用可配置 RSS/Atom 来源，天气使用可配置 JSON 接口，搜索使用用户指定的只读工具，不绑定供应商。
- B 站依赖 `astrbot_plugin_bilibili_ai_bot`，仅使用 `search_bilibili`、`watch_video` 和公开记忆 API v3。提供视频搜索、指定 BV 号观看、公开视频记忆读取三个入口，不调用完整自主浏览或互动流程。
- 支持日程安排阅读新闻、查看天气、浏览 B 站和搜索；也支持角色因聊天、已有见闻或活动中的临时兴趣主动调用。
- 将获取内容整理为角色可使用的见闻，保留来源，供聊天、日程调整、记忆和见闻笔记使用。
- 明确区分真实网络信息与角色虚构经历，获取失败不能被记作已经看到的真实内容。
- 对单个来源不可用和调用失败提供状态记录与恢复能力，使其他来源和生活活动能够继续运行。
- 搜索不算观看，读取旧视频记忆不算今天新观看；私人查询产生的见闻继续保留在所属场合。

## 依赖

- 基础任务提供模型选择、模块启停及外部调用所需的共用能力。
- 与日程任务对接计划行动和临时行动，与记忆、社交及笔记任务对接已获取的见闻。
- 与管理页面对接来源设置、运行状态和见闻查看。

## 验收效果

- 四类来源都能产生带来源的见闻，并在相关聊天或生活活动中被使用。
- 日程中的阅读任务能够实际执行，聊天引起的临时搜索也能得到结果并留下记录。
- 更换来源后对应能力继续可用；关闭一个来源模块时，其他来源及生活能力正常工作。
- 网络失败不会产生虚假获取记录，角色日常小插曲不会被当作网络事实。
