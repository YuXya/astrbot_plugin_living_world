# 07 日记与见闻笔记

> 状态：0.1.0 已实现并纳入自动化验证；真实生活与聊天材料的日记质量验收待完成。返回[主程总计划](../01-lead-plan.md)。

## 做什么

- 根据已有生活经历、互动和阅读内容，生成轻量日记、感想及见闻笔记，形成角色可以回顾的日常记录。
- 让日记体现当天实际经历与感受，见闻笔记保留内容来源，支持后续日程、聊天和主动表达检索相关内容。
- 区分角色虚构经历与真实网络信息；未执行的计划不能写成已经发生，失败的搜索或社交不能补写成成功经历。
- 延续原内容的使用场合，涉及具体谈话、私人经历或约定时，不通过日记与笔记将其变成跨场合共享内容。
- 提供运行时开关，关闭后停止对应生成与业务使用，保留已有记录，其他能力继续工作。
- 配合集中管理页面提供查看、必要的编辑与删除、导入导出和恢复操作。

## 依赖

- 基础接入提供模型、模块管理和恢复能力。
- 日程与生活状态、聊天和外部见闻提供已有经历及阅读结果；记忆能力提供回顾和检索支持。
- 集中管理页面承接日记与笔记的浏览及维护。

## 验收效果

- 当天的上课小插曲、真实互动与阅读见闻能形成符合角色的日记或笔记，并在后续回顾中找到。
- 内容能够追溯到已有经历或来源，不把未执行计划、私人谈话或虚构新闻写成公开事实。
- 关闭后停止生成及业务使用，重启和重新启用后保留的记录仍可查看、维护与检索。
