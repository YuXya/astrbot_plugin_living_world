# 07 日记与见闻笔记

## 任务内容

- 日记按目标日期从统一记忆回顾取材，笔记按主题召回；没有材料时跳过，不编造。
- 保留完整正文、事实依据和来源，事实与角色感想分开。未执行计划、失败搜索、未收到的回复不能补写成真实经历。
- 具体谈话、私人约定及衍生记录保留场合，遵守记忆和来源模块限制。
- 正文保存后进入统一后台记忆提炼，取消独立日记简报和笔记简报模型调用与按钮。旧正文及旧简报先归档，再通过统一迁移处理；原时间不被迁移时间替换。
- 日记与笔记独立启停，关闭保留历史；页面继续提供完整正文查看、生成、删除和备份恢复。

## 依赖

- 统一记忆提供日期回顾、主题召回、去重及材料队列。
- 基础模型、存储、调试、页面和生命周期。

## 验收效果

- 写作只使用新记忆系统提供的材料，保留虚构生活与真实阅读边界，无材料时跳过。
- 正文保存与后台提炼失败相互独立，失败不丢原文、不生成虚假成功状态。
- 不再执行旧简报路径，不单独注入日记正文。
- 私人内容不跨场合传播，关闭来源后衍生记忆仍遵守模块限制。

规则详见[统一记忆指南](../07-memory-system.md)；实际验证见[验收记录](../03-delivery-and-validation.md)。
