# 07 日记与见闻笔记

## 任务内容

- 依据已有生活经历、实际互动和阅读内容生成轻量日记、感想及见闻笔记。
- 保留来源与阅读依据，事实和角色感想分开，可供后续回顾和检索。
- 未执行计划、失败搜索、未收到的回复不能补写为真实经历，虚构小插曲与网络事实明确区分。
- 具体谈话、私人约定及衍生日记保留场合，公开见闻和角色自身生活按适用范围共享。
- 日记与笔记独立启停，关闭保留历史；页面提供查看、删除、导出与恢复。
- 先生成并保存完整正文，再调用一次模型提炼简报。只将简报写入派生记忆，不再复制整篇正文；简报和派生记忆事务采用，失败或取消保留正文和已有简报，删除中的记录不得被复活。正文保留完整来源，简报清理链接且受当前长度限制。
- 旧记录无简报时不参与自动召回，管理员可在日记页「生成简报／重新生成简报」。升级和恢复不自动批量调用模型；试跑与正式简报共用请求资料组装，试跑不改正文或记忆。含虚构日常的日记简报按原文日期只在当天召回，不伪造发生日期；知识笔记按原规则检索。

- 日记简报与笔记简报各有独立条数（初始各 1）及最长字符（初始各 200），在「02 上下文与提示词 → 上下文用量」配置；分类与用量、来源及实际标题一致，正文与回顾任务材料不占自动召回额度。

## 依赖

- 基础模型、存储、调试和生命周期。
- 日程、聊天、来源提供已发生材料；记忆提供回顾，页面提供历史浏览。

## 验收效果

- 生活小插曲和真实阅读形成可追溯回顾，搜索事实与角色感想可以分别查看。
- 日记不将计划或想象回应写成实际互动，不成为私聊资料跨场合传播通道。
- 重启和重新启用保留记录，关闭来源后其衍生内容遵守来源开关。
