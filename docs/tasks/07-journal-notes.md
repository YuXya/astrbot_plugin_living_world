# 07 日记与见闻笔记

## 任务内容

- 依据已有生活经历、实际互动和阅读内容生成轻量日记、感想及见闻笔记。
- 保留来源与阅读依据，事实和角色感想分开，可供后续回顾和检索。
- 未执行计划、失败搜索、未收到的回复不能补写为真实经历，虚构小插曲与网络事实明确区分。
- 具体谈话、私人约定及衍生日记保留场合，公开见闻和角色自身生活按适用范围共享。
- 日记与笔记独立启停，关闭保留历史；页面提供查看、删除、导出与恢复。

## 依赖

- 基础模型、存储、调试和生命周期。
- 日程、聊天、来源提供已发生材料；记忆提供回顾，页面提供历史浏览。

## 验收效果

- 生活小插曲和真实阅读形成可追溯回顾，搜索事实与角色感想可以分别查看。
- 日记不将计划或想象回应写成实际互动，不成为私聊资料跨场合传播通道。
- 重启和重新启用保留记录，关闭来源后其衍生内容遵守来源开关。
