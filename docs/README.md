# Living World 文档与任务索引

当前版本 **0.2.5**。新增独立“内在状态”模块管理寂寞值与精力，按在线时间增长、日程行动开始扣减，AI 只在活动细化时看到阶段文案。取消新闻、搜索和主动聊天的每日活动上限，保留每个对象的发送限制；旧细化与模板归档转换。调试固定四项、记录 SDK 实际 HTTP 正文，动态生活资料使用中文；保留 4.27.5 默认人格修复。真实在线模型、QQ、天气与 B 站账号联调仍需完成。

日记／笔记全文与上下文简报分开保存；「记忆与人物 → 上下文用量」可设置记忆总条数、其中日记／笔记上限和简报最长字符，默认 10／2／200。旧全文不自动注入，可在日记页生成简报；具体用法见安装与测试说明。
