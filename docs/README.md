「记忆与画像」现在先展示多人物卡片，再进入完整档案；五属性分组与发生时间视图可切换，另有全库搜索。摘要、分页内容、名字、版本和来源分开读取，保存局部更新。现有记忆归属与业务行为保持；本次只执行静态检查及打包语法校验，不运行回归或桌面冒烟，不安装、不提交或发布。

记忆统一为「记忆与画像」和「近期记忆」两个上下文入口：自身稳定画像默认 5 条、每人稳定画像 5 条、相关记忆 10 条、近期记忆 5 条，群聊最多 3 人，天气独立 1 条。用量位于「02 上下文与提示词 → 上下文用量」，0 停止对应注入，默认合计上限 36 条。近期记忆优先去重，按实际经历或获知时间跨日选择；未勾选项不影响其他项。日记与笔记保存正文后进入统一后台提炼，取消独立简报流程。详见[统一记忆指南](07-memory-system.md)。

管理页面现分为 8 个一级菜单及顶部二级面板；「02 上下文与提示词」集中上下文排序、上下文用量、提示词模板与调用记录。桌面上下文行高 32px，带拖动预览和来源索引；草稿按面板及对象保存，跨面板保存互不覆盖。用法见[管理页面指南](05-admin-navigation.md)和[上下文与调试指南](04-chat-context-and-debug.md)。
