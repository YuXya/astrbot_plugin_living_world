# Living World 主程任务计划（重构版）

> 状态：0.1.0 可安装测试版本已实现，自动化验证已开展；真实模型、QQ 和 B 站联调待完成。更新日期：2026-09-05。最终完成以全部保留功能通过真实验收为准，进度见[交付与验收记录](03-delivery-and-validation.md)。

## 一、目标与定位

制作一个 **private_companion 的轻量进化版**：一个由用户设定的角色，拥有连续日程，会阅读新闻、搜索、浏览 B 站、感受天气，并自然参与聊天。

**主动社交本身也可以是日程活动。** 例如“数学课有点无聊，找个群聊聊天”：AI 可以提前安排这项活动，也可以在活动过程中临时发起，结合目标群的聊天内容选择话题。

沿用 AstrBot 人格，插件补充角色资料、世界设定、生活状态和记忆。核心人设保持固定，持续积累经历、知识与人物关系。世界设定服务于轻量角色日常，不建设独立居民运行或夸张剧情系统。

独立提供生活和记忆能力，无需安装两个参考插件。首发完成 OneBot QQ 群聊与私聊支持。

## 二、开发任务

| 任务组 | 要做的内容 |
|---|---|
| [基础接入与模块管理](tasks/01-foundation.md) | 接入 AstrBot 人格、模型、会话和消息能力。建立模块注册、运行时启停、状态查看及恢复能力。统一默认模型，各模块允许覆盖。 |
| [角色资料与生活状态](tasks/02-character-state.md) | 提供角色资料、世界设定的编辑与使用能力。支持适度自定义的精力、情绪、作息，轻微影响活动与表达。不要饥饿系统。 |
| [日程与生活小插曲](tasks/03-daily-life.md) | 结合人设和相关记忆生成每日大纲，临近活动时细化。允许日程安排阅读、搜索、找群或个人聊天等实际行为。生成适量日常小插曲，支持聊天、约定和见闻引起日程调整。 |
| [记忆与人物认知](tasks/04-memory.md) | 借鉴 Angel Memory 的知识、事件、技能、情感分类，以及人物画像、共同回忆和自身体会。实现自动提炼、主动记忆、检索、更新、合并、普通记忆淡化和重要记忆保留。日程、聊天和主动表达都能调用相关记忆。 |
| [外部见闻](tasks/05-external-sources.md) | 分别建设新闻、搜索、天气、B 站模块。新闻、搜索和天气来源可替换；B 站使用已确认的 Bilibili AI Bot 搜索、观看及公开记忆接口。支持日程探索和临时调用，保留真实出处。 |
| [聊天与主动社交](tasks/06-social.md) | 支持正常被动回复、适度群聊插话、生活见闻分享，以及主动找人聊天。向模型提供主动社交调用能力，供日程执行或临时决定使用。按白名单权重随机抽选配置数量的对象，读取对应场合的上下文和相关记忆，选择话题并分别生成内容。 |
| [日记与见闻笔记](tasks/07-journal-notes.md) | 根据已有生活经历、互动和阅读内容生成轻量日记、感想及笔记，并可供后续回顾和检索。 |
| [集中管理页面](tasks/08-admin-ui.md) | 管理角色与世界资料、模块开关、模型、日程、来源及白名单权重。查看当前状态、记忆、人物认知、见闻、日记、主动消息记录和模型调用情况。支持必要的编辑、删除、导入导出与恢复操作。 |

### 共用行为

- 所有业务能力分别提供运行时开关。关闭模块保留已有数据，停止对应行为，其他模块继续工作。新闻、搜索、天气和 B 站分别可关闭，被动回复、群聊插话与主动联系分别可控。
- 日程触发的社交、模型临时发起的社交和生活分享，共用白名单、概率抽选、数量配置、频率、免打扰和重复发送控制。
- 权重代表抽中概率，每次抽取不同对象。低权重对象也有机会被选中，不采用相关性排序取前 N 名。
- 记忆遵循：**认识同一个人，谈话分场合**。称呼、稳定兴趣和关系认知可以贯通；具体谈话、私人经历和约定保留所属场合。AI 自己的生活经历和公开见闻共同使用。
- 日程可以回忆与 AI 有关的经历和约定；衍生的日程记录、日记、笔记和自身体会继续遵循来源场合，不能把私人内容转为公共分享。原始聊天历史沿用 AstrBot，插件保存提炼后的记忆与生活记录。
- 角色虚构经历、计划和真实行动结果保持区分。安排了聊天、搜索或阅读，不代表已经执行；消息发出不代表对方已经回应，后续记忆和日记记录实际结果。

## 三、实施顺序与分工

### 1. 共同基础

- 主程完成 AstrBot 接入、模块边界、共用能力及基本管理入口。
- 生活、记忆、外部见闻分别分工，并行建设；相互依赖的能力先约定交接内容，再集成验证。
- 页面随模块逐步接入。

阶段效果：角色资料和共用能力可用，各任务组能够独立推进，并能查看及开关已接入模块。

### 2. 生活与交流闭环

- 打通日程读取记忆、活动产生经历、聊天形成记忆、见闻影响日程。
- 接通日程中的实际行动和模型主动调用能力。
- 完成白名单概率抽选、主动聊天、生活分享和群聊插话。
- 加入日记与见闻笔记。

阶段效果：能够演示“安排生活 → 实际行动或形成小插曲 → 与人交流 → 留下记忆 → 影响后续日程”。

### 3. 完整功能与稳定性

- 补齐四类外部来源、管理页面、模块启停和恢复能力。
- 完成 QQ 群聊与私聊的整体验收。

阶段效果：所有保留能力均可使用、查看和控制，外部故障及重启不会破坏已有生活与记忆。

按任务分配负责人，不固定九个工位或并发人数。主程负责共用能力、依赖协调、联调和验收，各负责人负责所属能力。交接说明已完成内容、验证结果及剩余问题。

## 四、验收场景

- **生活连续**：生成当天日程，临近上课产生“忘带笔”的小插曲，之后聊天能够记得这件事。
- **日程能够执行社交**：日程出现“数学课无聊，找群聊天”，到时能够调用社交能力、抽选目标、结合群内话题发言，并记录实际发生的互动。
- **能够临时主动联系**：活动过程中产生聊天意愿时，可以主动调用社交能力；计划中的聊天只有实际执行后才记为已发生。
- **概率抽选正确**：按权重随机抽取配置数量的不同对象，低权重对象也有机会被选中，各对象收到符合聊天场合的表达。
- **记忆参与生活**：昨天的聊天约定能影响今天的日程；更新后的记忆能够替代旧内容。普通记忆会淡化，有用内容得到强化，重要记忆可以保留。
- **人物与场合正确**：同一人在群聊和私聊中能够被认出，私人谈话不会自动变成群聊分享内容。
- **见闻有效**：四类外部内容能形成相关见闻，角色虚构经历与真实网络信息能够区分。
- **模块独立**：运行中关闭探索、记忆、插话或主动联系等能力后，对应行为停止，其他功能保持可用，已有数据得以保留。
- **运行可恢复**：重启后接续当前日程与已有记忆，过期主动消息不集中补发；单个来源或模型调用失败不会拖垮整个插件。
- **可查看与管理**：页面能编辑设定和白名单、切换模块、查看实际行为与调用情况，并完成必要的记录修改、删除和导入导出恢复。

各任务组完成相应行为测试，主程组织完整场景联调；真实社交验证仅使用配置好的测试白名单。

## 五、文档与范围约定

- 保留一份主程总计划和按能力组织的任务卡，每项只写任务内容、依赖和验收效果。[文档索引](README.md)与[工程规则](../AGENTS.md)以本版为准。
- 旧产品专题、事件契约、模块卡、固定工位任务卡及 ADR 已由本版替换，历史内容保留在 Git 记录中。
- 不再固定九工位、强制全部消息总线化或要求逐项先写 ADR。具体实现方案交由开发任务处理，共用行为由主程协调。
- 不再要求插件独占人格、禁止聊天形成长期记忆、按相关性取前 N 名，或写死天气与 B 站来源。
- 本轮不安排完整世界模拟、其他居民自主运行、人格自我改写、梦境、多 AI 持续交流或复杂技能成长。
- 总计划以保留功能全部完成为终点，允许分阶段交付；公开发布和插件市场上架另行安排。
