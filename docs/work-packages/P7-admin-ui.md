# P7 管理页与运营工程师任务卡

> **English Summary:** P7 owns the event-driven admin control plane, redacted read models, audit views, import/export workflow, and the complete 1.0 Plugin Page. The UI never writes domain storage directly and trusts only domain result events.

## 目标

- 构建领域事件只读投影、健康聚合、管理命令状态和操作者审计。
- 为 1.0 构建完整 Plugin Page：总览、世界/日程、天气/探索、对象池/主动、诊断、导入导出。
- 让所有变更通过版本化命令事件进入领域模块，并展示受理、拒绝、超时与最终结果。
- 使用 AstrBot 管理权限，实施敏感字段遮蔽、导入预检、导出脱敏与恢复流程。

## 非目标

- 不直接读写领域模块存储、缓存或私有对象。
- 不自行实现认证，不绕过 AstrBot 管理权限，也不把密钥传到浏览器。
- `0.0.1` 不创建空页面、占位前端资源或业务配置 schema。

## 所有权

- 未来后端实现：`living_world/admin/`。
- Plugin Page 前端目录由 P0 依据届时 AstrBot 官方约定在 ADR 中固定后归 P7 所有。
- 对应测试：`tests/admin/`；Admin 职责卡、P7 任务卡及管理 API/权限 ADR 提案。

## 消费/发布的事件族

- 消费：全部 `kernel.*` 至 `proactive.*` 的可投影事实与结果，以及来自已授权页面的 `admin.*` 管理操作请求。
- 发布：`admin.*` 仅承载管理操作受理/拒绝/完成、投影、审计和导入导出生命周期；通过校验后另行发布目标领域自身 family 的 Command。
- 领域模块不消费 `admin.*` 作为业务命令；例如位置变更由 admin 编排后发布 `environment.location_change_requested`，最终状态以 environment 的领域事实为准。
- UI 发出命令不等于成功；只有领域事实或失败响应能更新最终显示状态。

## 允许修改范围

- 可修改 `living_world/admin/`、`tests/admin/`、经 ADR 固定的 Plugin Page 目录、Admin 模块卡和本任务卡。
- 管理 API/权限 ADR 与公共契约变更只提交 P0/P8 评审。
- 不得修改任何领域模块存储层、业务实现或 AstrBot 认证实现。

## 模拟依赖

- 全事件族固定状态流、重复/乱序事件、模块离线与投影重建 fixture。
- AstrBot 管理员/非管理员、过期会话、权限撤销和敏感字段样例。
- 正常/损坏/未知版本导入文件、导出脱敏与回滚场景。

## 交付物

- 管理命令端口、只读投影、健康聚合、审计查询与导入导出服务。
- 1.0 完整 Plugin Page 及命令进度、失败、dry-run 和敏感信息遮蔽交互。
- 权限、投影重建、导入预检/回滚和浏览器黑盒测试资产。

## 阶段任务

- **Wave 0/1：** 不创建占位页面；审阅领域只读事件和命令需求，等待契约稳定。
- **Wave 2：** 完成管理后端、投影重建、权限、页面、命令状态、审计和版本化导入导出。
- **Wave 2 联调：** 与 P6/P0/P8 覆盖 dry-run、主动总开关、模块离线、命令失败与恢复。
- **Wave 3：稳定化轮值：** 修复权限、敏感信息、投影乱序、浏览器兼容和备份恢复缺陷。

## 禁止越界

- 不直接访问或修改任何领域模块存储、缓存或私有对象。
- 不自行实现认证，不绕过 AstrBot 管理员权限或把密钥送到浏览器。
- 不在页面、审计、导出或错误中显示消息正文、完整上下文或明文凭据。
- 不让导入产生部分写入，也不把“请求已发出”显示为“配置已生效”。

## 联调对象

- 从 P2–P6 接收只读事件、领域命令、错误码、敏感字段和 mock。
- 从 P0 接收官方 Plugin Page 目录/接口 ADR，从 P1 接收健康与投影重建支持。
- 向 P8 提供管理员/非管理员 fixture、浏览器黑盒路径、导入损坏样例和审计查询。
- 向 P0 交付页面功能矩阵、兼容版本和发布所需静态资源清单。

## 验收门槛

- 每个 UI 变更均可追踪到命令、领域结果和操作者审计，且没有直写领域存储路径。
- 非管理员、过期会话和权限撤销即时失败；敏感信息扫描通过。
- 投影从事件全量重建结果一致，重复/乱序事件不会破坏显示状态。
- 导入预检失败零写入；导出带 schema 版本、完整性清单并默认脱敏。
- 页面黑盒覆盖正常、拒绝、超时、模块离线、dry-run、恢复和窄屏可用性。
