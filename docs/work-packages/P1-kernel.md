# P1 内核工程师任务卡

> **English Summary:** P1 owns the event bus runtime, clock, lifecycle, supervised tasks, persistence primitives, idempotent delivery support, and restart recovery. The kernel transports domain messages opaquely and contains no life-simulation policy.

## 目标

- 实现进程内版本化消息总线、订阅生命周期、请求/响应相关性和失败隔离。
- 提供真实/虚拟时钟、受监管后台任务、优雅关停与重启恢复。
- 提供模块自有存储所需的事务、迁移、幂等与健康基础设施，不建立共享业务表。
- 输出可观察性、任务健康与诊断事件，支持 P8 故障注入。

## 非目标

- 不解释或实现任何生活模拟、天气、记忆、对象排序和主动发送策略。
- 不建立全模块共享业务表，也不成为领域数据的统一仓库。
- 不自行改变公共 envelope 或事件语义。

## 所有权

- 未来实现：`living_world/kernel/`。
- 对应测试与模拟：`tests/kernel/`。
- 内核职责卡、P1 任务卡及由 P0 批准的内核 ADR 提案。

## 消费/发布的事件族

- 消费：`kernel.*` 生命周期/任务控制请求；所有其他 family 的 envelope 仅作为不透明路由负载。
- 发布：`kernel.*` 启动、就绪、时钟、任务失败/恢复、存储迁移与关停事实。
- 内核不得解释、修改或补全 `world.*` 至 `admin.*` 的业务 payload。

## 允许修改范围

- 可修改 `living_world/kernel/`、`tests/kernel/`、内核职责卡和本任务卡。
- 内核 ADR 与公共契约只提交提案，由 P0 审核；契约测试由 P8 所有。
- 不得修改其他业务模块实现、测试或数据迁移。

## 模拟依赖

- P0 提供的 envelope/family fixture、模块清单和生命周期适配器。
- 可控队列、临时存储、虚拟时钟、崩溃点与取消/超时注入器。
- 订阅者成功、异常、阻塞、重复确认和乱序处理模拟器。

## 交付物

- 总线、请求/响应、真实/虚拟时钟、生命周期和任务监管端口。
- 模块自有存储所需的事务/迁移/幂等基础设施与恢复工具。
- 可观察性、健康事件、测试 harness 和面向所有业务模块的 mock。

## 阶段任务

- **Wave 0：** 按 P0 契约完成总线端口、虚拟时钟、生命周期、任务监管、存储端口和测试 harness；交付模拟发布器/订阅器。
- **Wave 1/2 待命：** 只处理经复现的内核缺陷和容量问题，不替模块修复业务逻辑。
- **Wave 3：稳定化：** 与 P8 执行重复/乱序、断电点、迁移失败、任务崩溃、重启恢复和优雅关停测试。

## 禁止越界

- 不包含日程、状态、天气、记忆、对象评分或主动发送规则。
- 不创建所有模块共用的业务数据库或允许模块跨表查询。
- 不吞掉失败、无限重试或使用真实等待使测试不可控。
- 不自行扩展公共 envelope；变更先交 P0/P8。

## 联调对象

- 从 P0 接收 envelope 与生命周期契约，向 P2–P7 提供稳定端口、mock 和最小用例。
- 向 P8 提供可控时钟、故障注入、队列/任务诊断和恢复观察点。
- 将性能限制、投递语义和已知恢复边界写入交接包，不要求消费者了解内核私有实现。

## 验收门槛

- 请求/响应保留 `correlation_id`，超时/取消可复现，单个订阅者失败不拖垮其他订阅者。
- 虚拟时钟测试无真实 sleep；任务在卸载时全部可取消并完成清理。
- 重复或重放 envelope 能支持消费者幂等，迁移失败不会留下半升级状态。
- 内核健康事件可解释积压、失败和恢复，且不记录敏感 payload。
- 架构守卫证明 kernel 不依赖任何业务模块。
