# P2 世界模拟工程师任务卡

> **English Summary:** P2 owns World, Planner, and State: the AI's configured identity and world, intended schedule, and actual current activity. The work must remain deterministic under a virtual clock and produce life events without sending messages.

## 目标

- 建立 AI 单一身份、世界设定、叙事地点标识、世界规则引用和可版本化规则。
- 生成、调整和解释“计划做什么”的日程，不把计划误当成已发生事实。
- 根据时间、环境和规则推进“实际正在做什么”的状态并发布生活事实。
- 提供可重放、可恢复、可审计的世界模拟状态机。

## 非目标

- 不读取聊天历史，不生成对话内容，不选择目标或执行投递。
- 不直接访问天气、新闻、搜索、B站或 LLM 客户端。
- 不把用户会话信息纳入全局世界设定，也不伪造现实观察。
- 不拥有现实天气查询坐标、城市 ID 或时区关联；这些数据唯一归 P4/environment。

## 所有权

- 未来实现：`living_world/world/`、`living_world/planner/`、`living_world/state/`。
- 对应测试：`tests/world/`、`tests/planner/`、`tests/state/`。
- 三张模块职责卡、P2 任务卡及经 P0 批准的模拟规则 ADR。
- P2 只拥有叙事地点标识与世界规则引用；它们不能承载、复制或替代 environment 的现实位置配置。

## 消费/发布的事件族

- 消费：`kernel.*` 时钟/生命周期、`world.*` 配置请求、`planner.*` 调整请求、`environment.*` 只读天气/现实位置时间投影、`exploration.*` 可选观察。
- P2 仅消费 environment 投影，不持久化或重新发布其中的现实坐标、城市 ID 与时区关联。
- 发布：只发布 `world.*` 身份/设定事实、`planner.*` 日程生成/调整/触发和 `state.*` 活动开始/变化/结束 Event；memory 订阅这些领域事实并自行执行准入/记账。
- P2 不发布 `memory.*` 生活事实记录请求，避免领域 Event 与写入请求造成双写。
- 三个模块之间同样只用总线，不共享可变对象或跨表写入。

## 允许修改范围

- 可修改 `living_world/world/`、`living_world/planner/`、`living_world/state/` 及其对应测试、模块卡和本任务卡。
- 模拟规则 ADR 与公共契约变更只提交 P0/P8 评审，不直接合并。
- 不得修改环境、探索、记忆、主动或管理模块实现。
- 不得在 world/planner/state 配置或表中新增现实天气坐标、城市 ID、时区关联字段。

## 模拟依赖

- P1 的虚拟时钟、总线、存储/恢复端口和受监管任务 fixture。
- P4 的晴雨、极端天气、陈旧/不可用及现实位置时间最小投影；fixture 必须证明 P2 只读且不复制源位置配置。
- P5 的可选观察事件，以及固定随机种子/确定性规则输入。

## 交付物

- 单一 AI 身份/世界配置、日程计划器和实际状态机。
- 计划调整、活动推进、基于 environment 投影的跨日/时区行为与重启恢复。
- 生活事实事件、确定性回放场景和供 P3/P6 使用的 fixture。

## 阶段任务

- **Wave 0 后准备：** 审阅冻结契约，仅提交兼容性问题，不提前实现替代总线。
- **Wave 1：** 使用虚拟时钟与模拟天气完成世界 → 日程 → 状态 → 生活事实闭环；提供无主动发送演示。
- **Wave 2 交接：** 向 P6 提供候选触发 fixture，向 P7 提供只读状态/命令事件。
- **Wave 3：稳定化轮值：** 修复时间边界、恢复或状态机缺陷，不扩大产品范围。

## 禁止越界

- 不读取聊天历史、不生成对话内容、不选择对象或投递消息。
- 不直接调用天气、新闻、搜索或 B站客户端。
- 不把用户会话信息写入全局世界设定。
- 不用系统真实时间绕过 kernel 时钟，也不以随机性制造不可重放状态。

## 联调对象

- 从 P1 接收总线、时钟和存储端口；从 P4 接收只读天气/现实位置时间投影，从 P5 接收规范化观察事件。
- 向 P3 交付生活事实语义和回放样例，向 P6 交付候选触发与过期语义。
- 向 P7 交付只读投影事件及版本化变更命令，向 P8 交付确定性场景表。

## 验收门槛

- 固定世界、时钟与输入事件产生确定的计划和状态序列。
- 计划事实与实际状态明确分离；跳时、跨日、跨时区和重启不会重复开始/结束同一活动。
- 天气不可用时按明确默认策略继续模拟，不伪造真实天气。
- P2 持久层和导出中不存在现实坐标、天气城市 ID、时区关联；叙事地点标识不能反向解析或替代 environment 配置。
- 生活事实可供 memory 重放，且不含任何用户会话正文。
- 同一 world/planner/state Event 的重试或重放由 memory 幂等准入，不产生“Event + memory 写请求”两次入账。
- 在 Wave 1 验收中，LLM 与真实发送接口调用次数均为零。
