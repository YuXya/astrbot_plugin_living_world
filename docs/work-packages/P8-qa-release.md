# P8 QA、安全与发布工程师任务卡

> **English Summary:** P8 owns independent evidence for contracts, boundaries, privacy, security, failure recovery, end-to-end behavior, license hygiene, CI, and release readiness. P8 may block a release but does not silently fix or redefine domain behavior.

## 目标

- 建立契约测试、架构导入守卫、单元/集成/OneBot 端到端测试框架与 CI 门禁。
- 验证幂等、虚拟时钟、乱序/重复、故障降级、重启恢复、迁移和卸载清理。
- 执行跨会话隐私、凭据/日志扫描、提示注入、权限与主动发送安全测试。
- 审核 clean-room/许可证边界、发行物、远端全新安装和 AstrBot 市场清单。

## 非目标

- 不修改领域行为来掩盖失败，不降低断言或跳过阻塞用例。
- 不单方面定义产品或公共事件语义；歧义由 P0 与领域负责人裁决。
- 不在未授权真实目标上执行主动发送，也不保存真实消息、密钥或大段外部内容。

## 所有权

- 唯一拥有 `tests/contracts/`；同时拥有共享测试基础设施 `tests/architecture/`、`tests/integration/`、`tests/e2e/`，领域 fixture 与对应负责人共同评审。
- CI/发布配置提案：`.github/` 及发布检查脚本；根文件最终由 P0 串行合并。
- 测试/发布文档、P8 任务卡和 QA/安全 ADR 提案。

## 消费/发布的事件族

- 消费：全部事件 family 的 schema、fixture、模块健康/错误事件、候选发行物和许可证清单。
- 发布：测试结果与门禁证据；运行时仅使用测试专属探针订阅所有 family，不发布生产业务事实。
- 故障注入请求必须走正式测试端口或 `kernel.*` 测试 harness，不得直接改领域表制造结果。

## 允许修改范围

- 可修改 `tests/contracts/`、`tests/architecture/`、`tests/integration/`、`tests/e2e/`、测试/发布文档和本任务卡。
- 可提交 `.github/` 与发布脚本提案，根文件/CI 最终由 P0 串行合并。
- 不得修改领域实现；领域专属测试由对应负责人拥有，P8 只共同评审门禁覆盖。

## 模拟依赖

- P0 的全部 schema/兼容样例、P1 的虚拟时钟/故障注入和各领域 mock。
- 跨会话 canary、伪密钥、恶意提示、权限身份、迁移/断电与恢复 fixture。
- 隔离 OneBot 测试端、远端全新克隆环境和许可证/发行物扫描器。

## 交付物

- 契约测试、架构守卫、集成/端到端 harness、CI 门禁与可复现测试报告。
- 隐私/安全/提示注入/凭据/许可证证据和故障恢复矩阵。
- RC go/no-go 报告、全新安装记录、发行物校验与市场发布清单。

## 阶段任务

- **Wave 0：** 与 P0/P1 建立 envelope 兼容测试、导入守卫、虚拟时钟 harness、敏感信息扫描和最小 CI。
- **Wave 1 门禁：** 验证 P2–P5 的确定性、来源、降级、隐私与无发送闭环；只给证据，不代写领域实现。
- **Wave 2：** 与 P6/P7/P0 完成 OneBot、逐目标隔离、管理权限、dry-run、投影和导入导出黑盒测试。
- **Wave 3：稳定化：** 主持故障矩阵、迁移/恢复、长稳、全新克隆安装、发行物/许可证审核并出具 go/no-go。

## 禁止越界

- 不为了让测试通过而降低断言、跳过失败用例或直接修改领域行为。
- 不在 fixture/日志保存真实用户消息、真实密钥或受版权保护的大段内容。
- 不单方面改变产品/事件契约；发现歧义提交给 P0 和领域负责人。
- 不执行真实主动发送破坏性测试，除非使用明确授权的隔离测试账号和目标。

## 联调对象

- 从每个工位接收统一交接包、mock、失败注入点、迁移和敏感字段清单。
- 向领域负责人提供最小复现、期望契约和证据；修复后独立回归。
- 向 P0 提交逐门禁报告、遗留风险、许可证矩阵、发布校验和回滚演练结果。
- 发布后保留可复现的 CI 证据，不保存用户数据或密钥。

## 验收门槛

- 契约兼容、模块导入守卫、重复/乱序/超时/取消、虚拟时钟和重启恢复全部有自动化证据。
- 隐私 canary 证明无跨会话串话、无消息正文持久副本，凭据扫描零命中。
- dry-run/关闭模式真实发送为零；隔离 OneBot 测试覆盖成功、限流、超时、永久失败和重复回执。
- 管理权限、投影重建、导入预检/回滚和浏览器黑盒全部通过。
- 远端全新克隆可加载/热重载/卸载；版本、metadata、tag、CHANGELOG、LICENSE 与 clean-room 清单一致。
