# 我也在这个世界生活 / Living World

**0.2.5 可安装测试版本，支持 AstrBot `>=4.27.5,<5`、Python 3.12、OneBot QQ 群聊与私聊。** 新增独立“内在状态”模块：寂寞值与精力由程序按在线时间和日程行动调整，AI 只在活动细化时看到对应想法。取消新闻、搜索及主动聊天的每日活动上限，保留四项调试、API 实际 HTTP 原文与中文生活上下文。真实在线模型、QQ、和风天气及 B 站联调仍待完成。

角色沿用你选择的 AstrBot 人格，积累生活经历、知识和人物关系。每天先安排上课、散步、阅读等活动，细化时再结合具体需要安排新闻、搜索或主动聊天。角色虚构经历、计划和已经执行的真实行动分别记录；私人约定保留所属聊天场合。

## 日程与聊天

- **群聊回复要求可编辑。** 在「02 角色、模型与模块 → 群聊回复」修改，默认只回应一个重点、通常一句。固定注入到本轮 **user 最后、生活资料块外面**；保存后下一轮生效，工具后沿用本轮快照，不写入聊天历史。支持恢复默认，留空不附加；私聊及后台任务不使用此规则。
- 默认每天 **06:00** 生成一次正式活动大纲，共 **10 个活动**，只含时间、内容、地点和睡眠状态。生成时间和活动数修改默认次日生效。
- 默认提前 **10 分钟**细化活动。AI 结合活动、人格、状态、相关记忆、当天其余安排、近期实际行动及当前想法，决定是否安排三项行动，给出理由、意图和时间。允许全部不安排；每个活动每类最多一次，多类可共存，按 **新闻 → 搜索 → 聊天** 执行。
- 三类行动没有每日活动上限和额度预留。页面分别显示已安排、已开始、成功、失败和跳过，实际行动历史不会因重新生成日程或重启清零。
- **一轮主动聊天可以抽选多个不同对象**，只计一轮并扣一次寂寞值；各对象仍受白名单、每日发送上限、冷却、免打扰及防重复限制。未找到合格目标不扣值。
- 未开始活动可点击 **「细化活动／重新细化」**，填写“本次要求”，例如“这次专心散步，不安排主动聊天”；要求不写入公共模板。合格后替换旧细化，失败保留旧结果。自动细化失败后，在活动开始前至少间隔 60 秒再试一次；仍失败则保留活动大纲，不新增行动。
- **「编辑／批量调整未来活动」**只修改未开始活动大纲，保留活动总数；修改后旧细化归档作废，之后重新细化。私人场合调整保持场合隔离，过期行动不补发。
- **「重新生成日程」**用最新已保存参数重做今天整份大纲。合格后立即采用，旧版本和执行结果归档；失败保留旧日程。未来活动细化后照常执行，内在数值、实际行动记录、发送次数和冷却不重置。
- 主动消息在执行时结合目标场合的聊天历史与记忆生成，计划不会冒充已发送或已得到回复。独立随机阅读、搜索和临时主动联系已取消；正常回复、群聊插话分别控制。管理员手动读取来源是明确的真实调用，不扣内在状态。

## 内在状态

打开 **「内在状态」**，上方同时查看寂寞值、精力及下次细化会收到的想法，下方用两个按钮切换各自设置。可以直接应用当前值，另行保存增长、行动消耗和阶段文案；刷新预览不会覆盖未保存的设置。

- 范围均为 **0—100**，寂寞值初始 **0**，精力沿用已保存值，新安装默认 **70**。默认每在线小时各增加 **10**，按实际在线时长连续计算，显示及阶段匹配向下取整；离线不补涨、每天不重置，到 100 后不积攒。
- 每轮日程主动聊天默认减寂寞值 **10**；每次日程新闻、搜索默认分别减精力 **10**。增长及每项消耗均可调整为 0。实际开始扣，失败不退，数值不足仍可执行并最低归零；手动来源、试跑、被动回复、插话、天气及独立日报不扣。
- 默认 **0—40、41—80、81—100** 三阶段，可编辑文案及分界，用加号拆分阶段，删除时并入低一档、最低档并入下一档，始终覆盖整个范围。
- 寂寞值默认文案为“不是很想聊天”“想偷偷看一眼 QQ 聊天”“必须聊天”。**这些是给 AI 的倾向提示，程序不强制插入行动。** 精力文案表达对新闻阅读或搜索的兴趣，AI 可选一项、多项或不安排。
- AI 看不到数值、名称、阶段范围和增减规则，只有活动细化收到命中的自然语言想法，模型无法控制精力增减。阶段变化不会自动重新细化；需要立即调整时手动重新细化。
- 模块关闭后停止增长、扣减和注入，保留数据且允许人工修改；重新开启从当前值继续。正常保存周期为 60 秒，扣值、人工修改及正常退出会立即保存，异常退出最多丢失最后一个周期的增长。

## 白名单在哪里

打开插件的 **Plugin Pages → 左侧「聊天对象与白名单」**。首页「今日生活」顶部和「日程与行动」页也有直达按钮。

点击「添加聊天对象」，填写 **QQ 连接、群聊／私聊、号码、启用、权重**，再保存。完整会话 ID 自动生成，旧 UMO 配置继续兼容。人格和记忆使用实际会话场合判断；同一群开启独立用户会话后，也不会将某人的私人上下文混入其他场合。

**未聊过也可以接入。**「检查会话与历史」显示当前真实会话、人格和找到历史／首次对话／读取失败；只读取状态，不调用模型、不发送消息、不创建空会话。

0.2.2 中，“配置允许接入”仅表示连接和人格等配置有效；发送一条消息后再检查“最近实际注入”，可直达对应调试轮次。人格来源会区分宿主默认设置、当前对话指定和会话规则。聊天会携带当前时间、当前活动和当天日程摘要，无日程或模块关闭时明确说明。

Living World 组织角色资料、生活状态、日程和相关记忆，模型、工具及回复继续走 AstrBot。私聊使用当前选中的对话，动态资料放在本轮请求末尾，不重复存入历史；首次主动联系成功后存入宿主会话。群聊独立观察最近 24 条、12,000 字符，生成时替换重复宿主群历史，保存前恢复原始历史。观察不依赖插话开关或宿主群历史开关。

## 固定来源与见闻

| 能力 | 配置及行为 |
|---|---|
| 新闻 | 内置 BBC 中文、Google 新闻中文、Solidot、Hacker News、MIT Technology Review、Ars Technica；可逐项修改、启停和恢复默认。取得候选后由 AI 选择、读取并写感想。 |
| 搜索 | 自动使用 AstrBot 已配置的网页搜索服务；AI 结合活动和记忆选题，实际搜索后写见闻。普通页面无需填写工具名或参数名。 |
| 天气 | 固定和风天气，只需地点、API Host、API Key 或 JWT 凭据。连接测试不写生活数据；自动刷新成功间隔 90 分钟，失败退避 15 分钟，不调用 AI。 |
| B 站 | 固定依赖 `astrbot_plugin_bilibili_ai_bot` 的搜索、指定视频观看及公开记忆 API v3。缺失依赖只影响 B 站和依赖它的 AI 日报。 |
| AI 日报 | 黑鸦 Heya 默认 **12:00**、橘鸦 Juya 默认 **23:00**，时间可改，每路每天一次。不消耗内在状态，不额外触发聊天，重启不集中补读。 |

见闻分别保留标题、选择理由、事实摘要、角色感想、来源和阅读依据。无法读取正文时明确标为标题或订阅摘要；模型整理失败只保留实际证据，并标记为部分完成。B 站搜索不等于观看，旧视频记忆不等于新观看；日报确认作者和当日发布日期后才观看，无法核对则跳过。

## 安装、调试与升级

1. 在 AstrBot 插件管理中导入 `astrbot_plugin_living_world-0.2.5.zip`，安装其 `requirements.txt` 依赖后加载。可选依赖 Bilibili AI Bot 需另行安装配置；生活和记忆不依赖两个参考插件。
2. 打开 Plugin Pages，在「角色、模型与模块」绑定人格、补充角色与世界资料。模型可留空沿用宿主，或设置默认模型及业务覆盖。
3. 填写测试白名单，使目标会话在 AstrBot 中使用同一人格。宿主群历史可用于初始化；未开启时从新消息开始观察。使用本插件插话时关闭宿主概率回复，否则本插件暂停插话。
4. 在「日程与行动」设置大纲及细化参数，在「内在状态」调整数值和阶段，在「内容来源」配置外部能力，按需要开启模块。初次未绑定人格时不会自动行动；内在状态默认启用，主动社交、插话及外部能力默认关闭。
5. 在「调试与调用记录」展开一轮，查看 **①上下文与信息来源、②API 原始请求、③API 原始返回、④回复阅读版**。工具后请求及失败重试可切换查看。聊天默认保留最近 **10 轮完整记录**，后台每类 **10 次完整调用**。试跑只调用模型，不执行工具、不发 QQ、不改正式生活数据。

检查 AI 实际收到的内容，请用 **②API 原始请求**。它来自 AstrBot SDK 最终发送的 HTTP 请求体，保留消息、工具和附加参数，仅隐藏已知认证凭据；下载不套包装。③保存接口解析前的返回正文，流式为原始 SSE 文件；④单独整理文字、推理、工具、用量及采用结果。支持 DeepSeek/OpenAI 兼容 Chat Completions 和 OpenAI Responses；未适配、未调用或捕获失败明确显示，不用 Provider 参数代替。旧日志标为“旧版快照，非 API 原文”。正式日程另存生成输入快照、模型生成文本和校验后日程。详见[聊天上下文与调试指南](docs/04-chat-context-and-debug.md)。

**本次升级会自动转换旧细化。** 精力沿用当前值，寂寞值从 0 开始，历史行动不追扣；未开始活动的旧细化和决定先归档，再清空细化并重置尝试，保留大纲及场合。已开始活动保留决定与执行记录，旧精力增减不再生效。旧独立行动继续退出队列，不重放。生成、细化和调整日程的旧自定义模板备份后启用新默认模板，可在调试页查看旧指令；之后的新修改不被再次升级覆盖。

升级保留记忆、白名单、实际发送、冷却、执行及扣减防重记录，不改变 SQLite 表结构。配置与数据位于 AstrBot 插件数据目录的 `astrbot_plugin_living_world/living_world.sqlite3`；Plugin Pages 是唯一配置入口，没有 `_conf_schema.json`。备份包含管理员可见的私人资料及配置凭据，应在可信位置保存；恢复会合并缺失记录、保留已有 ID，并关闭包括内在状态在内的全部业务模块，旧数据转换后再参与运行，已退役活动不会重新获得执行资格。

完整步骤见[安装与测试说明](docs/02-install-and-test.md)，验证范围见[交付与验收记录](docs/03-delivery-and-validation.md)。开发安排见[总计划](docs/01-lead-plan.md)、[任务索引](docs/README.md)及[协作规则](AGENTS.md)。

当前为单角色轻量生活与记忆插件，不包含饥饿系统、其他居民、人格自我改写、梦境或复杂技能成长。能力参考 [private_companion](https://github.com/menglimi/astrbot_plugin_private_companion) 与 [Angel Memory](https://github.com/kawayiYokami/astrbot_plugin_angel_memory)，代码、提示词、页面和测试独立编写；许可证为 [MIT](LICENSE)。公开发布和插件市场上架另行安排。
