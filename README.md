# 我也在这个世界生活 / Living World

**0.2.0 可安装测试版本，支持 AstrBot `>=4.27.5,<5`、Python 3.12、OneBot QQ 群聊与私聊。** 本轮重构日程、内容来源、调试与首页；代码和自动化验证已完成，真实模型、QQ、和风天气及 B 站联调仍待完成。

角色沿用你选择的 AstrBot 人格，积累生活经历、知识和人物关系。每天的正式日程安排新闻、搜索和主动聊天，例如“数学课有点无聊，偷偷找群聊聊天”。角色虚构经历、计划和已经执行的真实行动分别记录；私人约定保留所属聊天场合。

## 日程与聊天

- 默认每天 **06:00** 生成一次正式日程，共 **10 个活动、2 个新闻标记、2 个搜索标记、3 个主动聊天标记**。时间和四个数量可配置，修改默认次日生效。
- AI 自己选择哪些活动带标记，同一活动可以重叠；按 **新闻 → 搜索 → 聊天** 执行，每种行动在该活动内最多一次。
- 只细化或调整未开始活动，保持配额和已有执行记录。启动时已过生成时间且当天缺少日程才补生成；过期行动不补发。
- 主动消息在执行时结合目标场合的聊天历史与记忆生成。白名单按权重随机抽取不同对象，并遵守抽选数量、频率、免打扰和防重复控制。**计划次数不等于最终发送次数。**
- 独立随机阅读、搜索和临时主动联系已取消。正常回复、群聊插话分别控制；日程外的旧主动联系入口不再发送消息。管理员手动读取来源是明确的真实调用，与计划次数分开记录。

## 白名单在哪里

打开插件的 **Plugin Pages → 左侧「聊天对象与白名单」**。首页「今日生活」顶部和「日程与行动」页也有直达按钮。

点击「添加聊天对象」，填写 **QQ 连接、群聊／私聊、号码、启用、权重**，再保存。完整会话 ID 自动生成，旧 UMO 配置继续兼容。人格和记忆使用实际会话场合判断；同一群开启独立用户会话后，也不会将某人的私人上下文混入其他场合。

## 固定来源与见闻

| 能力 | 配置及行为 |
|---|---|
| 新闻 | 内置 BBC 中文、Google 新闻中文、Solidot、Hacker News、MIT Technology Review、Ars Technica；可逐项修改、启停和恢复默认。取得候选后由 AI 选择、读取并写感想。 |
| 搜索 | 自动使用 AstrBot 已配置的网页搜索服务；AI 结合活动和记忆选题，实际搜索后写见闻。普通页面无需填写工具名或参数名。 |
| 天气 | 固定和风天气，只需地点、API Host、API Key 或 JWT 凭据。连接测试不写生活数据；自动刷新成功间隔 90 分钟，失败退避 15 分钟，不调用 AI。 |
| B 站 | 固定依赖 `astrbot_plugin_bilibili_ai_bot` 的搜索、指定视频观看及公开记忆 API v3。缺失依赖只影响 B 站和依赖它的 AI 日报。 |
| AI 日报 | 黑鸦 Heya 默认 **12:00**、橘鸦 Juya 默认 **23:00**，时间可改，每路每天一次。独立于日程配额，不额外触发聊天，重启不集中补读。 |

见闻分别保留标题、选择理由、事实摘要、角色感想、来源和阅读依据。无法读取正文时明确标为标题或订阅摘要；模型整理失败只保留实际证据，并标记为部分完成。B 站搜索不等于观看，旧视频记忆不等于新观看；日报确认作者和当日发布日期后才观看，无法核对则跳过。

## 安装、调试与升级

1. 在 AstrBot 插件管理中导入 `astrbot_plugin_living_world-0.2.0.zip`，安装其 `requirements.txt` 依赖后加载。可选依赖 Bilibili AI Bot 需另行安装配置；生活和记忆不依赖两个参考插件。
2. 打开 Plugin Pages，在「角色、模型与模块」绑定人格、补充角色与世界资料。模型可留空沿用宿主，或设置默认模型及业务覆盖。
3. 填写测试白名单，使目标会话在 AstrBot 中使用同一人格。群聊需开启宿主群历史；使用本插件插话时关闭宿主概率回复，否则本插件暂停插话。
4. 在「日程与行动」设置生成参数，在「内容来源」配置外部能力，按需要开启模块。初次未绑定人格时不会自动行动；主动社交、插话及外部能力默认关闭。
5. 在「调试与调用记录」查看完整请求、原始回复、工具返回及发送结果，可复制和下载 JSON；每个任务类别默认保留最近 **10 次**。先建立测试请求，再编辑并点击「仅调用 AI 试跑」，只产生测试结果，不执行工具、不发 QQ、不改正式生活数据。

调试保存的是 **Living World 交给 AstrBot 的调用参数**，包括人格、提示词、上下文、记忆、模型及参数，不是模型提供商最终 HTTP 报文。正常聊天记录标明宿主钩子的快照时点；第三方插件内部模型调用不在捕获范围。正式日程另外保存生成参数、完整请求和原始 JSON，不受调试记录清理影响。

升级保留旧记忆、白名单、当天已有日程和执行防重记录，新日程规则用于下一份正式日程。配置与数据位于 AstrBot 插件数据目录的 `astrbot_plugin_living_world/living_world.sqlite3`；Plugin Pages 是唯一配置入口，没有 `_conf_schema.json`。备份包含管理员可见的私人资料及配置凭据，应在可信位置保存；恢复会合并缺失记录、保留已有 ID，并关闭全部业务模块，检查后再启用。

完整步骤见[安装与测试说明](docs/02-install-and-test.md)，验证范围见[交付与验收记录](docs/03-delivery-and-validation.md)。开发安排见[总计划](docs/01-lead-plan.md)、[任务索引](docs/README.md)及[协作规则](AGENTS.md)。

当前为单角色轻量生活与记忆插件，不包含饥饿系统、其他居民、人格自我改写、梦境或复杂技能成长。能力参考 [private_companion](https://github.com/menglimi/astrbot_plugin_private_companion) 与 [Angel Memory](https://github.com/kawayiYokami/astrbot_plugin_angel_memory)，代码、提示词、页面和测试独立编写；许可证为 [MIT](LICENSE)。公开发布和插件市场上架另行安排。
